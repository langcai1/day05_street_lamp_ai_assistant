# 常见问题 FAQ

## Q：平台有哪些核心模块？

A：平台核心模块包括总览大屏、地图监控、设备中心、告警中心、能耗分析、运维中心、系统管理和 AI 小助手。

## Q：平台适合什么场景？

A：平台适合城市智慧照明管理场景，用于集中查看路灯设备状态、地图点位、告警情况、能耗趋势和运维工单，帮助管理人员快速定位异常并安排处理。

## Q：总览大屏能看什么？

A：总览大屏可以查看路灯总数、在线设备、离线设备、告警设备、今日能耗、区域分布、区域热力、异常占比、运行趋势、告警列表和今日能耗分析。

## Q：设备离线怎么办？

A：设备离线时，优先检查供电状态、通信网关、SIM 卡或网络信号、控制器运行状态和设备最近上报时间。如果同一路段多台设备同时离线，应进一步检查网关、配电箱、区域网络或供电侧问题。

## Q：多个设备同时离线说明什么？

A：同一路段或同一区域多台设备同时离线，通常不是单灯故障，更可能是通信网关、配电箱、区域网络或供电侧问题。应优先排查公共链路。

## Q：单台设备离线怎么排查？

A：单台设备离线时，优先检查控制器、通信模块、SIM 卡、接线端子、单灯供电和最近上报日志。

## Q：告警中心怎么处理告警？

A：先查看告警等级、类型、设备编号、区域、道路和发生时间，再进入设备详情核对运行数据和最近日志。确认影响范围后判断是否需要派单，现场处理完成后更新工单状态并关闭告警。

## Q：哪些告警需要优先处理？

A：一级和二级告警、主干道照明中断、大面积离线、多设备集中告警、电压异常影响多台设备、夜间关键时段照明异常，都应优先处理。

## Q：电压异常怎么办？

A：先查看设备详情中的电压、电流和功率，判断是单灯异常还是区域异常。单灯异常检查电源模块和接线端子，区域异常检查配电箱、线路负载和供电侧。

## Q：通信异常怎么办？

A：通信异常时，先查看设备最近上报时间，再检查网关、网络信号、SIM 卡、通信模块和区域网络。如果同一路段多台设备异常，优先检查网关或网络链路。

## Q：灯具故障怎么办？

A：灯具故障时，检查 LED 灯头、驱动模块、接线端子、亮度数据、电流和功率。夜间主干道灯具故障应优先派单。

## Q：能耗分析页面有什么作用？

A：能耗分析页面用于查看今日能耗、趋势变化、区域能耗排行、设备能耗排行和异常能耗设备，帮助判断调光策略是否生效，并发现异常常亮、设备离线或采集异常等问题。

## Q：为什么要看近 7 天和近 30 天能耗？

A：近 7 天适合观察短期波动和近期策略调整效果，近 30 天适合观察长期趋势、月度变化和持续性异常。

## Q：能耗突然升高怎么办？

A：先对比昨日同小时曲线、亮灯率、平均功率和区域热力。如果亮灯率不变但能耗升高，重点检查异常常亮、调光策略失效、单灯功率异常和传感器误报。

## Q：能耗突然下降怎么办？

A：需要确认是否存在大面积离线、误关灯、调光策略过低、供电异常或采集数据缺失。

## Q：Cesium 地图加载失败怎么办？

A：先检查 Cesium runtime 是否加载成功，再检查 Cesium Ion Token、网络访问、底图模式、浏览器控制台错误和地图容器尺寸。如果 Ion 底图失败，可切换备用卫星底图或 OSM。

## Q：地图没有底图怎么办？

A：检查 Cesium Ion Token 是否配置、Token 是否有效、浏览器是否能访问外部瓦片服务、`VITE_CESIUM_BASEMAP` 是否配置正确，以及备用底图是否可用。

## Q：地图出现绿色道路或文字标签怎么办？

A：这是底图样式问题。建议使用 Cesium Ion 无标签卫星影像，避免带道路标签的底图覆盖业务点位。业务道路发光线应由前端实体渲染。

## Q：GeoServer WFS 502 怎么办？

A：检查 GeoServer 是否启动、端口是否正确、`VITE_GEOSERVER_PROXY_TARGET` 是否正确、WFS 图层和工作区是否正确。GeoServer 失败时，前端应返回空 `FeatureCollection`，继续加载本地路灯点位。

## Q：路灯点位为什么不显示？

A：检查本地点位 JSON 是否加载成功，字段是否包含 `lng` 和 `lat`，经纬度是否为数字，点位图层是否关闭，相机是否定位到正确区域，以及图标资源是否加载成功。

## Q：后端接口连不上怎么办？

A：检查后端是否启动在 8081 端口，前端 `/api` 代理是否指向后端，数据库是否连接成功，JWT 是否有效，以及浏览器网络面板中的接口状态码。

## Q：部署后页面能打开但数据不显示怎么办？

A：优先检查 `/api` 反向代理是否正确、后端是否启动、数据库是否可用、登录 token 是否有效、接口是否返回 401、403 或 500。如果地图数据不显示，还要检查 `/geoserver` 代理和本地点位文件。

## Q：登录后又跳回登录页怎么办？

A：通常是 token 不存在、token 过期、后端 JWT 密钥不一致或接口返回 401。检查 `localStorage` 中是否有 `smart_lamp_token`，并确认后端鉴权配置正常。

## Q：平台支持碳排分析吗？

A：碳排分析属于能耗分析模块的规划能力，当前尚未作为完整生产功能接入。后续可基于能耗数据扩展碳排估算。

## Q：平台支持告警联动吗？

A：告警联动属于告警中心的规划能力，当前尚未作为完整生产功能接入。现阶段平台重点围绕告警列表、告警详情、告警处理流程和工单流转进行管理。

## Q：平台支持备件管理吗？

A：备件管理属于运维中心的规划能力，当前尚未作为完整生产功能接入。现阶段运维中心重点支持工单列表、工单筛选、工单详情，以及告警、巡检、维修、固件升级、能耗异常等工单处理。

## Q：Dify 知识库应该上传什么？

A：Dify 知识库应上传平台说明、使用说明、设备排查、告警流程、能耗说明、地图排障、接口字段、部署运维和 FAQ 等资料，不应上传 API Key、数据库密码、服务器密码、`.env` 文件、`node_modules`、`target`、`dist` 或完整源码。

## Q：Dify 助手后续如何接入？

A：可以把 `docs/dify_knowledge` 中的 Markdown 上传到 Dify 知识库，再通过 Dify 应用嵌入或 Chatflow 接入前端 AI 小助手。后续如需查询实时设备、告警、能耗数据，可通过 Dify HTTP Request 节点或 Spring Boot 后端代理调用业务接口。
