# 后端接口与数据字段

## 后端概览

后端项目位于 `lamp-service`，包名为 `com.example.lampservice`，启动入口为：

- `LampServiceApplication.java`

默认服务端口：

- `8081`

后端使用 Java 17、Spring Boot、Spring Web、Spring Security、Spring Data JPA、PostgreSQL、Flyway 和 JWT。

## 鉴权规则

公开接口：

- `GET /api/auth/captcha`
- `POST /api/auth/login`
- `POST /api/auth/register`
- `POST /api/auth/reset-password`

权限规则：

- `/api/system/**` 需要 `SUPER_ADMIN` 或 `ADMIN` 权限。
- 其他 `/api/**` 需要登录。
- 登录后前端通过 `Authorization: Bearer <token>` 访问接口。

## 认证接口

### GET /api/auth/captcha

作用：获取验证码。

用途：

- 登录前校验。
- 注册前校验。
- 重置密码前校验。

返回内容包括验证码 key、验证码内容和过期时间。

### POST /api/auth/login

作用：用户登录。

请求字段：

- `username`
- `password`
- `captcha`
- `captchaKey`

返回字段：

- `token`：JWT。
- `user`：用户信息。

### POST /api/auth/register

作用：注册新用户。

请求字段：

- `username`
- `password`
- `confirmPassword`
- `realName`
- `phone`
- `email`
- `captcha`
- `captchaKey`

规则：

- 用户名为 3 到 32 位字母、数字或下划线。
- 联系方式支持手机号或邮箱。

### POST /api/auth/reset-password

作用：重置密码。

请求字段：

- `username`
- `phone`
- `email`
- `newPassword`
- `confirmPassword`
- `captcha`
- `captchaKey`

## 大屏接口

### GET /api/dashboard/summary

作用：获取首页大屏统计数据。

返回字段：

- `total`：路灯总数。
- `online`：在线设备数。
- `offline`：离线设备数。
- `alarm`：告警设备数。
- `maintenance`：维护设备数。
- `todayEnergy`：今日能耗。
- `onlineRate`：在线率。

### GET /api/dashboard/area-distribution

作用：获取区域设备分布。

用于：

- 区域分布图。
- 区域设备数量列表。

常见字段：

- `name`：区域名称。
- `value`：设备数量。
- `percent`：占比。
- `color`：展示颜色。

### GET /api/dashboard/area-heatmap

作用：获取区域热力数据。

常见字段：

- `name`：区域名称。
- `level`：热力等级。
- `value`：热力值。
- `alarmCount`：告警数量。
- `deviceCount`：设备数量。

### GET /api/dashboard/exception-ratio

作用：获取异常类型占比。

常见异常类型：

- 电压异常
- 通信中断
- 灯具故障
- 能耗异常
- 其他

### GET /api/dashboard/running-trend

作用：获取运行趋势。

参数：

- `range=today`
- `range=7d`
- `range=30d`

返回内容用于展示在线率、亮灯率、平均功率、能耗等趋势。

### GET /api/dashboard/alarm-list

作用：获取告警列表。

参数：

- `limit`：返回数量，默认 20。

常见字段：

- 告警等级
- 告警类型
- 设备名称
- 设备编号
- 区域
- 道路
- 发生时间
- 状态

### GET /api/dashboard/today-energy

作用：获取今日能耗数据。

用于：

- 今日能耗图表。
- 今日能耗汇总。

## 设备接口

### GET /api/device

作用：获取设备列表。

参数：

- `keyword`：搜索关键词。
- `status`：设备状态。
- `limit`：返回数量，默认 500，最大 1000。

返回字段：

- `id`
- `deviceName`
- `deviceCode`
- `areaName`
- `roadName`
- `status`
- `longitude`
- `latitude`

### GET /api/device/search

作用：搜索设备。

参数：

- `keyword`：关键词。

规则：

- 关键词少于 2 个字符时返回空列表。
- 最多返回 10 条。

匹配字段：

- 设备名称
- 设备编号
- 区域
- 道路

### GET /api/device/{id}/detail

作用：获取设备详情。

返回字段：

- `id`
- `deviceName`
- `deviceCode`
- `type`
- `areaName`
- `roadName`
- `installLocation`
- `installTime`
- `status`
- `longitude`
- `latitude`
- `voltage`
- `current`
- `power`
- `brightness`
- `runHours`
- `todayRunHours`
- `temperature`
- `signalStrength`
- `logs`

如果设备不存在，返回 404 和提示信息。

## 系统用户接口

### GET /api/system/users

作用：查询系统用户。

权限：管理员或超级管理员。

### POST /api/system/users

作用：创建系统用户。

权限：管理员或超级管理员。

请求字段：

- `username`
- `password`
- `realName`
- `phone`
- `email`
- `role`
- `status`

### PUT /api/system/users/{id}

作用：更新用户信息。

### PUT /api/system/users/{id}/status

作用：更新用户启用或禁用状态。

### PUT /api/system/users/{id}/reset-password

作用：管理员重置用户密码。

### DELETE /api/system/users/{id}

作用：删除用户。

## 系统日志接口

### GET /api/system/logs

作用：查询系统操作日志。

常见字段：

- 操作人
- 模块
- 动作
- 内容
- 结果
- IP 地址
- 操作时间

## 天气接口

### GET /api/weather/current

作用：获取当前天气。

页面顶部可展示天气信息，例如温度和天气状态。

## AI 助手与后端接口规划

当前 Dify 知识库主要用于回答平台功能说明、设备排查、告警处理、能耗分析、地图排障、后端接口和部署运维问题。

Dify 助手后续可通过 Chatflow 的 HTTP Request 节点调用 Spring Boot 后端接口，实现业务数据查询能力，例如：

- 调用 `GET /api/device/search` 查询设备。
- 调用 `GET /api/device/{id}/detail` 查询设备详情。
- 调用 `GET /api/dashboard/summary` 查询平台总览指标。
- 调用 `GET /api/dashboard/alarm-list` 查询告警列表。
- 调用 `GET /api/dashboard/today-energy` 查询今日能耗。

在正式接入 Dify API 时，建议后端增加代理接口，统一处理 Dify API Key、安全鉴权、请求日志和错误兜底，避免前端直接暴露敏感配置。
