# 智慧路灯数字孪生管理平台 AI 助手

## 1. 项目简介

本项目基于 **Dify** 搭建了一个面向「智慧路灯数字孪生管理平台」的企业资料 AI 助手。

助手围绕项目已有资料进行知识库问答，能够回答平台功能、系统架构、前端页面、后端接口、Cesium 地图、设备状态、告警处理、能耗分析、运维排查和 RAG 接入方案等问题。

该项目不是普通聊天机器人，而是一个结合 **WebGIS 项目资料 + Dify 知识库 + Chatflow 编排 + System Prompt 约束** 的企业资料智能助手。

---

## 2. 项目背景

智慧路灯数字孪生管理平台由 **Vue 前端大屏** 和 **Spring Boot 后端服务** 组成，核心目标是把城市路灯设备、运行状态、告警、能耗、运维和地图点位统一管理起来。

原项目中已经包含：

- 登录注册
- 总览大屏
- Cesium 三维地图
- 设备列表
- 设备详情
- 告警中心
- 能耗分析
- 运维中心
- 系统管理
- AI 小助理入口
- JWT 鉴权
- mock 兜底能力

本项目在此基础上，将项目资料整理成 Dify 知识库，并通过 AI 助手实现资料问答、运维辅助和办公内容生成。

## 3. 项目目标

本项目的目标是搭建一个可演示、可扩展的企业级 AI 助手雏形，具体包括：

1. 搭建 Dify 知识库
2. 使用高质量 Embedding 检索
3. 构建 Chatflow 问答流程
4. 配置严格的 System Prompt
5. 支持平台介绍和功能问答
6. 支持前后端架构说明
7. 支持后端接口查询
8. 支持设备离线、告警、能耗和地图异常排查
9. 支持产品介绍、日报、客户回复、PPT 大纲等办公内容生成
10. 对资料外问题和实时数据问题进行拒答或边界说明

## 5. Dify 工作流设计

当前 Chatflow 流程如下：

```text
用户输入
↓
知识检索
↓
LLM
↓
直接回复
```

### 节点说明

| 节点 | 作用 |
|---|---|
| 用户输入 | 接收用户问题 |
| 知识检索 | 从智慧路灯知识库中召回相关片段 |
| LLM | 根据 System Prompt 和知识库上下文生成回答 |
| 直接回复 | 将 LLM 结果返回给用户 |

## 6. 知识库设计

### 当前知识库版本

```text
智慧路灯数字孪生管理平台_Dify知识库V4.1_事实版
```

### 知识库设计原则

V4.1 知识库采用“事实知识库”设计，不把大量行为指令、测试问题、面试表达和长篇办公模板放入知识库。

知识库只保留项目事实资料，例如：

- 平台定位
- 核心功能
- 前端页面
- 后端能力
- 系统架构
- 登录认证
- 大屏接口
- 设备接口
- Cesium 地图说明
- 设备状态与设备详情
- 告警中心
- 离线排查
- 能耗排查
- 地图异常排查
- 系统管理
- AI 小助理与 RAG 规划
- mock 兜底与实时数据边界

### 知识库优化过程

知识库经历了多个版本迭代：

| 版本 | 说明 |
|---|---|
| V2 | 合并式知识库，包含较多 FAQ、模板和行为规则 |
| V3 | 严格版，删除部分泛化内容，减少模型乱编 |
| V4 | 事实版，行为指令与事实知识分离 |
| V4.1 | 最终优化版，移除助手身份章节，减少重复召回，接口清单改为索引式 |

## 7. System Prompt 设计

System Prompt 用来控制助手行为，而不是放在知识库中。

主要约束包括：

1. 助手身份为“智慧路灯数字孪生管理平台 AI 助手”
2. 回答必须优先基于知识库检索结果
3. 不允许编造知识库中没有的技术栈、设备类型、数据库、中间件和商业信息
4. 资料外问题回答“资料中未找到相关信息”
5. 实时设备状态、真实告警、真实能耗需要接入数据库或后端接口后才能回答
6. 办公生成类问题可以基于知识库事实生成结构化内容
7. 回答应简洁、准确、分点清晰

```text

```

### 8.2 技术架构问答

可回答：

```text

后端有哪些接口？
JWT 鉴权是怎么做的？

```

### 8.3 运维排查问答

可回答：

```text
设备离线应该怎么排查？

通信类告警怎么排查？
能耗升高怎么排查？
地图无底图怎么办？
```

### 8.4 办公内容生成

可生成：

```text
请根据资料生成一段平台产品介绍。
请帮我写一段客户回复：客户反馈设备一直离线。
请生成一份项目日报。
请生成一份平台介绍 PPT 大纲。
```

### 8.5 拒答与边界控制

对于资料外问题，助手应拒答：

```text
平台价格是多少？
公司创始人是谁？
公司有哪些客户案例？
```

对于实时数据问题，助手应说明需要接入数据库或接口：

```text
LAMP-001 当前是否在线？
今天有哪些真实告警？
当前实时能耗是多少？
```

## 12. 当前项目边界

当前助手主要基于知识库回答问题，暂时不能直接访问真实设备数据库。

因此：

- 可以回答平台功能、接口、架构和排查思路
- 可以生成项目介绍、日报、客户回复和 PPT 大纲
- 可以说明实时数据需要接入数据库或接口
- 不能直接判断某个具体设备当前是否在线
- 不能直接查询今天真实告警
- 不能回答知识库中没有的价格、客户案例、公司人员等信息
